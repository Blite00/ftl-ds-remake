# V35 crew selection and launch setup

- In crew view, tap empty space around the ship or press **B** to deselect all crew. A room tap cannot issue movement while deselected. Tap a portrait or use **L/R** to select again. Tapping the selected portrait still opens crew details.
- **B** closes an open panel first. From plain crew view it clears selection; press **B** again to open the combat jump map or leave management. The FTL touch button opens the jump map directly.
- **New Run** opens crew setup before creating the campaign. Tap one of the three names, edit it with the keyboard, then choose **OK**. D-pad moves the keyboard cursor, **A** enters a character, **X** deletes, **B** cancels that edit. Choose **LAUNCH** to start with those names. On the name list, **B** returns to the main menu with the prior run intact. Default names are allowed; no save is replaced by setup or launch.

Earlier controls and feature details follow. The V35 rules above supersede earlier B-button descriptions.

# V33 controller guide

## Main menu

Up/Down selects and A activates; touch the large option rows directly. Continue appears when a valid checkpoint is available. Start on the map opens Resume Run; B resumes. New Run asks for confirmation when a saved or live run exists and leaves the save file unchanged until explicit SAVE. Finale toggles the flagship numbers for the next new run: TUNED (default, DS-balanced) or ORIGINAL (FTL normal difficulty). Each run keeps its choice in its save. Controls and Sound are also available here. Victory/defeat returns to this menu.

## Combat and crew management

| Button | Crew view | Aiming view |
| --- | --- | --- |
| D-pad | Highlight a destination room | Select target room |
| L / R | Select previous / next living crew | Select previous / next weapon |
| A | Order selected crew to highlighted room | Fire; mark endpoints first for a beam |
| Y | Aim in combat; next management tab between fights | Return to crew |
| X | Pause / resume | Pause / resume |
| B | Back; retreat map from combat crew view | Back to crew |
| Start | Actions menu | Actions menu |

The Actions menu holds simulation. Up/Down selects rows and moves through pages. A activates; Left/Right adjusts selected system power. Touch +/- buttons also adjust power. Doors identify airlocks and room endpoints. Sound cycles OFF/LOW/MED/HIGH, with HIGH as the default. Weapon power and autofire apply to the selected weapon.

Boarding: L/R selects crew, D-pad selects a room, Y changes the viewed ship, A orders the selected party, and Start opens party selection/gather/send/recall/power actions. Ship availability, party size, charging and room requirements still apply.

Drones retain their dedicated menu: Up/Down selects, A acts, Y changes tabs, L/R adjusts power, X pauses and B closes. Combat/home-defense input also accepts Left/Right for drone power.

Map: Left/Right or L/R selects a beacon and moves the zoomed view; Up toggles the sector overview; B recenters on your ship. A jumps; Down waits; X saves; Y opens management; Start opens the main menu. Touch selects the nearest visible beacon; the same ALL/ZOOM and CENTER actions are available on screen. Events: Up/Down selects, A confirms, L/R reads text pages. Surrender holds combat until you explicitly accept or refuse; an escape warning requires Continue before the charge resumes. Rewards: Up/Down selects, A accepts/confirms, B declines/cancels.

## Remaining controller gaps

This milestone provides the combat loop, crew movement, power, doors, targeting, autofire, beam/bomb selection, boarding actions and existing drone/event/map navigation. Some upgrade/equipment operations, crew naming and specialist confirmation screens still require touch. Held-button repeat and complete end-to-end controller-only campaign acceptance remain open. Physical button comfort and readability on the revised build need a human DS playtest.
